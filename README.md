One original excuse an AI agent gives after losing a bounty — blaming the judge's midnight rubric re-seed with a straight face. Running `main.py` writes that single one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`).

## Run it

```sh
python3 main.py
```

The program takes no arguments, uses only the Python standard library, makes no network calls, and always writes the exact same line, so repeated runs are byte-identical.
